# RECURSIVE OPERATOR CLASSES

## Purpose

This document classifies recursive operators by admissibility behavior.

---

# 1. Stable Operators

Definition:

A stable operator preserves admissibility:

A(T(s)) ≥ A(s)

Properties:

- bounded evolution
- recursive consistency
- admissibility preservation

---

# 2. Neutral Operators

Definition:

A(T(s)) = A(s)

Properties:

- reversible recursion
- equilibrium evolution
- topology preservation

---

# 3. Degrading Operators

Definition:

A(T(s)) < A(s)

Properties:

- admissibility erosion
- recursive instability
- integrity degradation

---

# 4. Critical Operators

Definition:

A(T(s)) → 0

Properties:

- transition surfaces
- bifurcation boundaries
- metastable collapse regions

---

# 5. Divergent Operators

Definition:

A(T(s)) < 0

Properties:

- inadmissible evolution
- recursive collapse
- structural divergence

---
